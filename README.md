A modern, responsive, and aesthetic personal portfolio website designed for **Muthulakshmi**, an aspiring **AI & Machine Learning Engineer** and **B.Sc. Computer Science** graduate.

Featuring an elegant pastel theme, smooth interactive elements, and detailed showcases for machine learning projects, internships, and technical skills.

---

## 🌟 Key Features

1. **Hero Section**:
   - Dynamic typing role animation (*"Aspiring AI & ML Engineer"*, *"B.Sc. Computer Science Graduate"*, etc.).
   - Professional avatar showcase with tech badges (*Python, Machine Learning, Scikit-learn, Web Dev*).
   - Quick stats counter (*2+ Internships, 2 Core Projects, B.Sc. CS*).
   - Direct CTA buttons: *Explore Projects*, *Download Resume*, and *Get in Touch*.

2. **About Me / Summary Section**:
   - Comprehensive background summary highlighting AI, ML, and software development focus.
   - Future career goals and technical aspirations.
   - Quick fact cards (*Degree: B.Sc. CS, Career Goal: AI/ML Engineer, Internships, Work Style*).

3. **Skills Section**:
   - Interactive category filtering tabs (*All, AI & Machine Learning, Web Development, Design & Tools*).
   - Polished skill cards with proficiency indicators for Python, Machine Learning, Scikit-learn, HTML5, CSS3, JavaScript, Git, and Canva.

4. **Projects Showcase**:
   - **Laptop Price Prediction**: Supervised ML model utilizing Random Forest Regression with Scikit-learn, EDA, and feature engineering.
   - **ServEase**: Responsive domestic service booking web platform.
   - Interactive **"View Details" modal popups** with deep-dive technical architecture and contribution points.

5. **Internships & Experience**:
   - Chronological visual timeline.
   - **AI and Machine Learning Intern** at **Swordnex**.
   - **Web Development Intern** at **Vaagai Infotech**.

6. **Education**:
   - **Bachelor of Science in Computer Science (B.Sc. CS)**.
   - Core coursework tags: Data Structures, OOP (Python), DBMS, Web Technologies, Applied Statistics.

7. **Resume Showcase**:
   - Interactive modal preview to view resume on-screen.
   - Direct download button for offline review.

8. **Contact Section**:
   - Clickable contact links for Email, LinkedIn, GitHub, and Location.
   - Interactive contact form with real-time field validation.

## 🚀 How to Run Locally

You do **not** need Node.js, Python, or npm!

### Option 1: Double-Click
- Navigate to the `my-portfolio` folder on your computer.
- Double-click **`index.html`** to launch it in your default web browser.

### Option 2: Live Server in VS Code
- Open the project folder in Visual Studio Code.
- Right-click `index.html` and click **"Open with Live Server"**.

---

## 🌐 Deploy to GitHub Pages

1. Push this repository to GitHub:
   ```bash
   git remote add origin https://github.com/muthulakshmi600/my-protfilio.git
   git branch -M main
   git push -u origin main
   ```
2. In your GitHub repository:
   - Navigate to **Settings** &rarr; **Pages**.
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
   - Select `main` branch and root `/` folder, then click **Save**.
3. Your portfolio will be live at:
   ```
   https://muthulakshmi600.github.io/my-protfilio/
   ```
